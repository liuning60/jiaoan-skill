# 教案结构模板（lesson-structures）

按学段（大学 / 初高中）与模式（整本 / 单节）选择结构。整本 = 封面 + 课程信息表 + N 次课教案表；单节 = 一节课的教案表。

## 大学教案（含高职、中职）——整本

参照通用高校教案本结构，栏目清单如下：

### 封面
| 字段 |
|---|
| 学校名称 |
| "教案" |
| 学年学期（如 2026～2027 学年第 一 学期） |
| 院（系、部）/ 教研室 |
| 主讲教师 |
| 课程名称 |
| 教授专业 |
| 授课班级 |
| 落款（×××学校教务处制） |

### 课程基本信息表
| 字段 |
|---|
| 课程名称 / 课程代码 / 课程类别（必修/选修） |
| 授课对象（本科/高职等）、专业年级班 |
| 任课教师、职称 |
| 课程教学目标 |
| 教学重点与难点 |
| 主要教学方法与手段（讲授/讨论/案例/上机/实验等） |
| 教材 |
| 主要参考资料 |

### 每次课教案表（每课一张，按课时/周次编号）
| 栏目 |
|---|
| 授课时间（第 N 次课、周次、节次） |
| 课时 |
| 授课方式（理论/讨论/习题/实验/上机/技能等，勾选） |
| 授课题目（本章节课题名） |
| 目的与要求 |
| 重点与难点 |
| **时间安排（必填行）** |
| 教学基本内容：教学过程（含六要素案例）、案例步骤、评估方式 ｜ 方法及手段 |
| 小结 / 课后小结 |
| 思考题 / 作业 / 参考文献 |

### 组装规则
- 整本模式按课时总数（或周次）生成 N 张教案表，编号连续，课时合计等于总课时。
- 授课题目按"章-节-知识点"三级展开，与课程信息表中的教学目标对齐。
- 单次课时长 = 课时 × 45 分钟（如 4 课时 = 180 分钟）；时间安排各环节分钟相加必须等于该值。

## 时间安排（必填行）

- 每张教案表新增一行 **"时间安排"**：以表格式/分行式列出各环节——导入、讲授、演示、学生练习、巡回辅导、点评小结——每环节标注分钟。
- **上机/实训环节必须拆出"学生独立练习 X 分钟"和"教师巡回辅导 X 分钟"两项**。
- 全部环节时长相加必须等于本次课总课时。**先定预算再写内容**，杜绝内容不足或超时。
- 示例："【时间安排】导入 10′｜讲授 40′｜演示 15′｜上机：独立练习 45′＋巡回辅导 15′｜点评小结 25′｜合计 180′"

## 教学过程排版规范（解决"内容挤在一起"，必须执行）

实测教训：教学过程挤在一个段落里不可读；采用"小标题逐行 + 内容分行"：

1. **【时间安排】加粗独占一行**，各环节（导入 10′ / 讲授 40′ / …… / 合计 180′）每项一行。
2. **环节标题加粗独占一行**（如"环节二 行业认知与岗位版图（40′）"），内容"①②③④"每项一行。
3. **案例名加粗独占一行**（"案例 1（六要素）· 案例名"）；六要素各自成段——【案例背景】【与教学目标的关系】【实施过程】【成果与数据】【教学点评】【课堂提问】加粗小标题独占一行，内容行（步骤/提问 ①②③ 每项一行）。
4. **上机/实训**："任务——…"与"学生独立练习 45′，教师巡回辅导 15′"分行。
5. **【评估方式】**各条目每项一行。
6. 行距 1.15；标题行段前 8-12pt，内容行段后 3-4pt。
7. 图片区与正文分离：每张图前留白（10pt）、图注后留白（14pt）；每张图配图注"图 N ｜ 标题 ｜ 来源"。

## 初高中教案——单节（常见结构）

| 栏目 |
|---|
| 课题、课型（新授课/复习课/实验课） |
| 课时安排 |
| 教学目标（三维目标：知识与技能 / 过程与方法 / 情感态度与价值观） |
| 教学重点、教学难点 |
| 教学方法（讲授/探究/合作/演示等） |
| 教学准备（教具、多媒体、实验器材） |
| 教学过程：导入（5 分钟）→ 新授（含案例演示）→ 练习巩固 → 课堂小结 → 布置作业 |
| 板书设计 |
| 教学反思（课后填写） |

## 单节教案（大学）

大学单节教案 = 一张"每次课教案表" + 可选的课程信息头（课程名、教师、班级）；同样围绕课程人才培养方案/教学目标。

## 选择顺序

1. 学段 → 大学（含高职/中职）或初高中；
2. 模式 → 整本（封面+信息表+N 课表）或单节（单张教案表）；
3. 用户提供学校模板 → 完全按模板栏目（见 template-and-update.md），本文件仅作无模板时的默认结构。
