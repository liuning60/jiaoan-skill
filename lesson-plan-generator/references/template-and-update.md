# 套学校模板与老教案更新（template-and-update）

每个学校都有自己的教案格式。本技能不预设单一格式，而是"读结构、按栏目填"。实测支持"多模板"：用户可提供多份学校模板，任选一份作为本次生成框架。Word 读写/验收在豆包环境走 word skill 流程；其他平台按 SKILL.md「跨平台工具映射表」替换为宿主文档能力，验收标准不变。

## 场景 A · 套学校模板

用户提供学校模板 .docx（或 .doc，需先按 word skill 转 .docx 基线）。

流程：
1. **读取并解析模板结构**（走 word skill 流程）：
   - 封面字段（学校名、学期、院系、教师、课程、班级……）
   - 课程信息表栏目（教学目标、重点难点、方法、教材……）
   - 每次课教案表的栏目（授课时间、课时、授课方式、题目、目的要求、重点难点、教学基本内容/方法、小结、思考题作业）
   - 固定内容（如"教务处制"、页面设置、页眉页脚）与示例内容区分：**示例内容要替换，固定内容保留**
2. **建立栏目映射**：模板栏目 ↔ 本技能内容引擎输出的字段，形成填写计划（template-plan）。
3. **按模板填充**：封面填学校信息；信息表填课程信息；每课表按编号连续填充，课时合计等于总课时；图片按 image-engine 插入对应栏目。
4. **验收**：按模板逐栏目核对（word skill 的 audit + template-plan 验收），固定内容未被改动，示例内容已清理。

## 场景 B · 老教案更新

用户提供旧教案 .docx，并说明更新点。

流程：
1. **读取旧教案**，识别其结构（封面 / 信息表 / 每次课表或单节课表）。
2. **收集更新点**：换教材 / 改学时 / 替换案例 / 新增知识点 / 更新教学目标等（用户可用自然语言说明）。
3. **保留式定点更新**：只改用户点名的栏目与内容，其余段落、表格、图片、格式一律保留原样。
4. **输出新版 Word**；同时询问是否需要"按新课程名从零重写"版作为对照（生成规则见 SKILL.md 主流程）。

## 实测踩坑与解法（必须遵守）

### 1. 模板内容行的定位：按"表头行"定位，不要按内容行开头文字
- 同一模板里每张教案表的内容行开头文字可能完全不同（如某表是"教学过程:"，另一表是"分形杂色:"、"1.快速方框模糊:"）。
- **错误做法**：按内容行开头关键词（"教学过程"/"案例步骤"）定位 → 会漏掉开头不同的表，导致该节内容、图片全没填（整本 18 节漏 2 节）。
- **正确做法**：先定位"教学基本内容"表头行（每表固定），取**表头行的下一行首格**作为内容区。

### 2. 封面替换注意空格
- 模板封面文字常带空格（"主 讲 教 师 刘宁"），直接匹配"主讲教师"会失败。匹配前先对段落文本**去除空格再判断**（`text.replace(' ','')`），替换时再定位原 run。

### 3. 清理模板的旧示例内容
- 旧教案模板内部可能自带大量旧图（如 194 张、48MB）。套用时先把模板做成"无图清洁版"（移除所有 w:drawing、media 关系、media 文件），否则成品 docx 体积巨大（240MB+）。
- 清洁版同样作为 audit 的 --source。

### 4. 图片体积控制
- 生成图嵌入前压缩：长边 ≤1000px、JPEG 质量 85；108 张图整体 7-8MB。原图另存 PNG 备查。

### 5. Word 占用导致无法覆盖
- 目标 docx 正被 Word 打开时覆盖会 PermissionError。处理：先生成到临时文件名（如"-排版优化版.docx"）→ audit 验证 → 请用户关闭原文件后替换（Move-Item -Force）→ 替换后重跑 audit/回读验证再交付。
- 反复修改时，每次都用"新临时文件名"输出，避免自己锁住自己。

### 6. 时间安排不要重复拼接
- 数据层 process[0] 已含"【时间安排】"行时，脚本不要再拼一行（会出两行时间安排，一简一详）。直接用 process 原列表渲染。

### 7. 生成图 OCR 错字检查
- AI 生成图内的标题文字常有错字（如"色彩三要素"→"色色三因素"、"图形创意"→"图形创意步法"、"IP图案延展图库"→"景观示图"）。交付前逐图检查，发现错字重刷该图。

## 通用约束

- Word 的一切读写、套模板、编辑、验收**必须**走 word skill 流程，禁止自写简化读取器。
- 模板中的示例文字、虚构数据不是事实来源；用户要求与用户材料决定实际内容。
- 未要求改动的模板内容不得擅动。
