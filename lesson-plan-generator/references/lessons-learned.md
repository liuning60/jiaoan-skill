# 实测踩坑记录（lessons-learned）

本文件沉淀 lesson-plan-generator 在真实实测（高职《数字视觉设计》整本教案：18 次课 × 每节 6 图 = 108 图，套郑州旅院模板）中发现的问题与最终解法。执行本 skill 前建议通读，避免重复踩坑。

## 一、用户九条反馈（v1 → v2 改造依据）

| # | 反馈 | 最终解法 |
|---|---|---|
| 1 | 没有学校教案模板 / 不同学校格式不同 | 套模板走"读结构、按栏目填"；支持多模板任选；模板与内容引擎做栏目映射 |
| 2 | 生成前应搜人才培养方案，出教学目标和教学内容，等待用户核实（用户会仔细看，约 500 字） | 整本模式必做"预研核实"：检索人才培养方案/专业教学标准 → 出约 500 字目标框架 → 用户核实后再生成 |
| 3 | 每个教案生成图片数量不少于 N 张 | 配图下限：上机/实训 ≥6、混合 ≥5、理论 ≥4（张/节） |
| 4 | 懒人审核：回复数字代表指令，不要求打字 | 废除三数字打分，改为单数字协议：1 继续｜0 生成全部｜2 图片｜3 案例｜4 内容｜5/6/7 组合｜9 全部重做 |
| 5 | 课时长内容不够填，需细化上课内容，写清学生练习和老师辅导时间 | 时间预算：教案表新增"时间安排"行；上机必须拆"学生独立练习 X′＋教师巡回辅导 X′"；环节分钟相加 = 总课时 |
| 6 | 批量生成明显偷懒；软件操作类缺图严重 | 配图下限强制；整本逐节核对图片数量；生成后统计每节 blips |
| 7 | AI 生成图有水印，教学不允许 | 生图 prompt 强制"无水印、无logo、无文字水印"；网图跳过带水印源 |
| 8 | 网上同类案例图可以直接放，怎么取舍需用户审核 | 案例图优先真实网图并标来源；拿不准版权/水印/模糊的降级 AI 生成；归属"图片"维度让用户数字确认 |
| 9 | 案例没有详细可操作的内容 | 案例六要素强制：背景/与目标的关系/实施过程（≥3 步可操作）/成果与数据（无数据写定性）/教学点评/课堂提问（≥2） |

## 二、v2 追加需求（用户二次确认）

- **分层教学**：是否按学生水平分层设计任务 → 加入生成前必问项。
- **配图偏好必问**：全 AI / 网图优先 / 混合；案例配图是核心，能找到真实图最好，其余 AI 生成。
- **界面图选项必问**：A＝全 AI 生成不留截图占位（老师通常不自己截图）；B＝留截图占位。
- **案例六要素删除"讲法建议"**：仅保留 6 要素；成果与数据可选（不是每个案例都有）。
- **数字协议细化**：0＝生成全部不再审核；废除三数字打分，新增组合数字（5/6/7）代表不同组合重做。
- **全课融入 AI（AIGC）**：所有内容贯穿 AI 使用（AI 生成素材、AI 辅助设计、人工判断精修）。

## 三、排版迭代（"内容挤在一起"问题）

| 版本 | 问题 | 解法 |
|---|---|---|
| v1 | 教学过程长文本挤在一个段落 | 段落化：每行一个段落 + 行距 1.15 + 段前后留白 |
| v2 | 仍是长行，环节/案例标题不突出 | 小标题逐行：环节标题、案例名、六要素标签、【时间安排】全部加粗独占一行；内容按 ①②③ 每项一行；上机拆"任务…/独立练习45′巡回辅导15′"两行；【评估方式】每项一行 |
| 最终 | 时间安排出现两行（简+详） | 数据 process[0] 已含【时间安排】，脚本不再拼接 |

## 四、工程性坑（生成 docx 全流程）

1. **模板旧图膨胀体积**：模板源自带 194 张旧教案图（48.7MB）→ 套用前先做"无图清洁版"（移除 w:drawing + media 关系 + media 文件，0.1MB）再填充 → 成品 5.9-6.8MB。
2. **原图嵌入膨胀**：2048px 级 PNG ×108 嵌入 → 246MB；压缩到长边 1000px JPEG 质量 85 → 7.2MB。
3. **漏填定位**：按"教学基本内容"表头行的下一行定位内容区，不要按内容行开头文字（不同表开头不同）→ 曾漏第 13、15 节（内容+图全空，blips 只有 96/108）。
4. **封面空格匹配**："主 讲 教 师 刘宁"含空格 → 先去除空格判断关键词，再替换原 run 中的旧值。
5. **Word 占用覆盖失败**：目标文件被 Word 打开 → PermissionError；输出临时文件名 → 用户关闭后 Move-Item -Force 替换 → 重跑 audit + 回读验证。
6. **生成图 OCR 错字**：标题文字错写（"色色三因素""图形创意步法""景观示图"等）→ 逐图检查重刷。
7. **交付**：图片压缩版复制到用户桌面配图文件夹（lesson01-18 子目录）供自查；docx 用 present_files 交付，说明待填占位（教师姓名/班级/课程代码/职称）。

## 五、验收清单（每次生成后）

- [ ] audit（--source 清洁模板）退出码 0
- [ ] 图片逐节统计 = 节数 × 每节配图下限（如 18 × 6 = 108）
- [ ] 每节【时间安排】只出现一次，环节分钟相加 = 总课时
- [ ] 封面占位符明确（×××待填），未编造教师/班级/课程代码
- [ ] 案例无编造数据（无来源不写数字，写"定性成果，无公开数据"）
- [ ] 全文无 AI 错字图、无水印图
- [ ] 模板固定内容未动，示例内容已清理
