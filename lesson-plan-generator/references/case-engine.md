# 案例引擎（case-engine）

目标：消灭"内容空洞"——每个知识/技能点都有**具体、可核对、可操作**的案例支撑。实测结论：案例空洞的根因是"只写背景不写过程、只提概念不落步骤"，必须用六要素把案例写"实"。

## 双通道获取

按优先级：
1. **联网检索真实案例**：按知识点/主题搜索行业真实项目、软件官方案例、知名作品、时事案例。
   - 例：讲 AE 特效 → 搜某综艺片头、某广告的实际制作案例；讲数字视觉 → 搜天猫AI营销、知名IP、影视案例。
   - 检索到的案例必须标注来源；检索整理的内容一并提示老师核对（"公开案例·检索整理，请老师核对"）。
   - 案例相关的配图优先用真实网图（见 image-engine）。
2. **内置案例模板兜底**：检索不到合适案例时，用下表的学科主题案例框架生成，保证永远有案例可用。

## 结构化案例格式（六要素，强制）

每个案例按以下六段输出，缺一不可（**删除"讲法建议"要素**）：

```
案例背景            —— 这个案例是什么、发生在什么场景（时间地点主体）
与教学目标的关系     —— 为什么用它来讲这个知识点
实施过程            —— 老师怎么带学生走一遍（分步骤、可操作，≥3 步，每步描述具体动作）
成果与数据           —— 最终产出了什么（作品/数据/结果）；无公开数据时写"定性成果，无公开数据"，禁止编造数字
教学点评            —— 好在哪里、容易错在哪、可迁移到什么场景
课堂提问            —— ≥2 个课堂问题（让学生主动思考，可带参考答案要点）
```

### 关键要求（实测总结）
- **实施过程必须详细可操作**：至少 3 步，每步写清"做什么、怎么做"（如"①设定为…性格，②通过园区互动…积累粉丝"），禁止"演示该案例"式空话。
- **成果与数据是可选项**：不是每个案例都有公开数据。有可靠来源才写具体数字并标注"检索整理，请老师核对"；没有就写定性成果，**绝不编造数据**。
- **定性成果写法模板（无公开数据时，v1.1）**：按"做了什么 → 达到什么效果/标准 → 可验证依据"三段式写，禁止编数字。示例：
  - "学生完成《××》动态海报并投放到校园数字屏播放，视觉效果达到甲方验收标准（课堂定性成果，无公开数据）"
  - "作品入围校级创新展并通过指导教师验收（定性成果，无公开量化数据）"
- **案例必须紧扣该课教学目标**，禁止为凑案例而堆砌。
- 每个新知识点至少 1 个案例；重点难点知识点可 2 个（一个讲透 + 一个迁移）。

### 产教融合关联（职业院校可选强化，v1.1）

职业院校（高职/中职）课程优先给案例标注产教融合关联：案例实施过程若可落到真实岗位任务，写一行 **"产教融合：对应《××》课程的企业××岗位任务"**（如电商美工岗的详情页设计任务）。有明确岗位对应就写，无则不写，不强制、不编造岗位。

## 内置案例模板（兜底，按学科主题分类）

| 学科类别 | 案例框架示例 |
|---|---|
| 计算机 / 数字媒体 | 真实项目复盘：某 App/影视/游戏片段 → 拆解技术步骤 → 学生复刻关键步骤 → 对比原作点评 |
| 经济 / 管理 | 知名企业决策案例：背景 → 数据/决策 → 结果 → 与理论模型的对应 → 课堂讨论点 |
| 法律 / 政治 | 典型案例或判例：案情 → 争议焦点 → 判决/依据 → 对概念的印证 → 延伸思考 |
| 语言 / 文学 | 文本细读案例：选段 → 语言特征分析 → 与理论/时代背景关联 → 仿写任务 |
| 理工 / 医学 | 经典实验或事故案例：现象 → 原理推导 → 数据佐证 → 安全/伦理引申 |
| 艺术 / 设计 | 代表作品拆解：作品 → 技法/风格要素 → 步骤演示 → 学生创作任务 |
| 初高中学科 | 生活化情境案例：场景 → 知识关联 → 探究活动 → 结论归纳 |

兜底案例必须在文末标注"示例案例，请老师替换为本地真实案例"。

### 完整示例（v1.1，供复刻，理工/医学）

以"离心泵汽蚀"（化工机器基础）为例，完整六要素写法：

```
案例背景：某化工厂循环水泵运行 3 个月后流量下降、噪声异常，检修发现叶轮入口处蜂窝状蚀坑。
与教学目标的关系：用于讲"汽蚀现象及危害"，把抽象的空泡理论落到真实设备故障。
实施过程：① 展示泵解体照片/动画，观察叶轮蚀坑位置；② 讲解汽蚀形成链：入口压力<饱和蒸气压→气泡产生→到高压区溃灭→冲击叶轮金属面；③ 结合 NPSH（装置汽蚀余量）公式算该泵是否满足要求；④ 给出改造方案（提高入口液位/换泵）。
成果与数据：故障图片与检修记录（课堂演示资料，无公开数据，属定性成果）。
教学点评：学生易把"汽蚀"与"气缚"混淆——汽蚀在叶轮内部、气缚在吸入管；迁移到给水泵、船舶螺旋桨等场景。
课堂提问：① 为什么汽蚀多发生在叶轮入口背面？② 泵流量下降时如何区分汽蚀和气缚？
```

> 框架式模板仅给出结构；实测案例应尽量补齐为上述完整写法，理工/工程类课程至少内置 1 个本学科完整案例。

## 案例标题规范

案例在教案中的标题格式：`案例N（六要素）·案例名`（如"案例1（六要素）·天猫618「AI玩行动」"）。渲染时案例名加粗独占一行，六要素各自成段（【背景】【与教学目标的关系】【实施过程】【成果与数据】【教学点评】【课堂提问】加粗小标题 + 内容行），详见 lesson-structures 排版规范。
