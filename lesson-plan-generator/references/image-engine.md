# 配图引擎（image-engine）

目标：消灭"满页文字"——每份教案图文并茂、可读性强。实测教训：软件操作/实训类课最容易被砍图，配图下限强制 + 生成图两类硬伤（水印、OCR 错字）必须防。

## 配图下限（按课程类型，强制）

- **上机/实训类：≥6 张/节**
- **混合类（理论+上机）：≥5 张/节**
- **理论类：≥4 张/节**

整本模式逐节核对；低于下限必须补齐；批量生成时不得"偷懒"（每节配图数齐额）。

## 组合策略（按优先级执行）

1. **案例图优先真实网图**：案例相关内容（真实作品、案例截图、实拍、同类作品）用 image_search / 通用搜索检索。
   - 案例是核心：真实图说服力强（如讲 IP 主题搜玲娜贝儿/泡泡玛特官方图，讲海报搜知名海报）。
   - 第三方图：图注标注来源（"公开案例，由检索资料整理，请核对"）；不把第三方图 URL 直接当交付物。
   - **取舍规则**：只对"真实案例/作品展示"用网图；版权不明、带水印、模糊的跳过，降级 AI 生成或占位；取舍让用户在交互审核（图片维度 2）里确认。
2. **AI 生成教学示意**：检索不到合适图时（抽象内容：流程、架构、对比、示意图、界面概念图），用宿主图像生成能力生成。
   - **生成 prompt 强制加"无水印、无logo、无文字水印、无边框"**——从源头消灭教学不允许的水印。
   - 用于抽象概念可视化，标注"AI 生成示意图"。
   - **生成后检查 OCR 错字**：AI 图内嵌标题文字常错（如"色彩三要素"→"色色三因素"），发现错字必须重刷，禁止带错字交付。
3. **占位标注兜底**：以上都不合适时写"此处建议插入：XX 图（来源建议：教材第×页 / 官网 / 实拍）"；界面图选项 B 时在指定位置写截图占位。

## 界面图选项（生成前必问）

- **选项 A（推荐）**：全部 AI 生成，不留截图占位——老师通常不自己截图，A 最省事、拿到即用。
- **选项 B**：留"此处插入 XX 截图"占位，供老师课后补自己课堂截图。

## 图源与版权

- 优先选用：教材配图、官网、官方案例图、可商用图源（标注作者/站点）。
- 一律标注来源；拿不准版权的图不采用，降级到 AI 生成或占位标注。
- 不把第三方图的 URL 直接当交付物；真实图以"来源注 + 图注"形式进入教案。

## 位置与图注

- 图放在对应知识点的段落附近，配图注："图 N ｜ 标题 ｜ 来源（AI 生成 / 公开案例）"。
- 图注按节连续编号（第 N 节用 N- 前缀：图 1-1、1-2……），与图片文件夹命名一致（lesson<N>_img<M>.jpg）。

## 插入 docx 与体积控制

- 图片插入 Word 走宿主文档流程（asset 处理、等比缩放、不裁剪原信息）。
- **体积控制（真实实测）**：108 张 2048px 级原图直接嵌入 → docx 240MB+；嵌入前压缩（**长边 ≤1000px 的 JPEG、质量 85**）→ 108 张共 7-8MB；模板自带的旧示例图片也要清理（模板可能自带 40MB+ 旧图，先做无图清洁版再填充）。
- 压缩图与原图分开保存：原图（PNG）归档备查；压缩版（JPEG）用于嵌入和交付配图文件夹。
